# advent_of_code_2025
Refreshing my skills using 2025's advent of code! 🎄

## Day01: Entering the North Pole ⭐️⭐️
Move a circular dial to open the door
- Part 1: Move the dial and count the number of times it lands on '0'. 
- Part 2: Move the dial and count the number of times it passes '0'.

## Day02: The Gift Shop  ⭐️⭐️
Identify invalid product IDs for the elves  
- Part 1: any id where digits are repeated twice  
    ex. 55 (5 twice), 6464 (64 twice), and 123123 (123 twice)  
- Part 2: any id where a sequence of digits is repeated *at least* twice  
    ex. 12341234 (1234 two times), 123123123 (123 three times), 1212121212 (12 five times), and 1111111 (1 seven times)

## Day03: The Lobby ⭐️⭐️
Identify the maximum joltage per battery from each elevator
- Part 1: Highest joltage possible using 2 batteries
- Part 2: Highest joltage possible using 12 batteries

## Day04: The Printing Department ⭐️⭐️
We made it to the printing department but the elevators are still down... so we are going to break through the cafeteria wall using a forklift! However, we first need to optimize forklift work so we can use some of the extra time to break through the wall.
- Part 1: Count how many paper rolls are removable if we don't remove anything right away
- Part 2: Count how many paper rolls are removable if we iteratively remove them

## Day05: The Cafeteria ⭐️
After breaking down walls between the cafeteria and printing room, we are helping the elves in the kitchen by processing data from the new inventory management system in the cafeteria.
- Part 1: Count how many of the listed items are fresh
- Part 2: Count all of the possible fresh IDs
